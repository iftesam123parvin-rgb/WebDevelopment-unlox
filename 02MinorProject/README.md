
# AURORA Smartphone Landing Page

## Project Overview

AURORA is a fictional smartphone brand created as part of the Minor Project: Responsive Product Landing Page.

The website showcases a modern smartphone through a clean,
responsive landing page built using HTML5, CSS3, Flexbox,
CSS Grid, media queries, and JavaScript.

## Features

- Responsive navigation bar with a mobile hamburger menu
- Hero section with smartphone imagery and call-to-action buttons
- Smartphone features and benefits
- Customer testimonial section with illustrative reviews
- Product pricing and colour options
- Footer with contact information and social links
- Responsive layouts for mobile, tablet, and desktop



## Responsive Design

CSS Grid, Flexbox, and media queries are used to adapt the
website to desktop, tablet, and mobile screens.

## Disclaimer

AURORA is a fictional brand created for educational purposes.
Product specifications, pricing, and testimonials are
illustrative examples and do not represent a real product.
